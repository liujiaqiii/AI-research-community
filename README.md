# AI Research Community: Figure Reproduction Package

This repository provides the plotting notebook and compact processed tables used to reproduce the study's main figures on researcher entry, novelty, transient participation, career survival, geographical diversity, and citation inequality in AI and traditional scientific fields.

## Repository structure

```text
.
├── figures_plotting_code.ipynb
├── README.md
├── requirements.txt
├── data/
│   ├── source_newcomer_inflow_growth.csv
│   ├── source_transient_by_cohort.csv
│   ├── source_pooled_km_5year.csv
│   ├── keyword_novelty_histogram_bins.csv
│   ├── keyword_novelty_summary.csv
│   ├── source_country_ai_six_disciplines.csv
│   └── source_citation_gini_ai_six_disciplines.csv
└── figures/
    ├── figure1_entry_growth_and_novelty.png
    └── figure2_transience_survival_country_citation.png
```
